# Практическая работа № 3: версионирование данных и моделей

Проект по дисциплине «Технологии анализа данных».

Цель — построить воспроизводимый ML-пайплайн и сравнить три модели классификации изображений на исходных данных и данных с аугментацией.

Репозиторий: https://github.com/bigboynixxik/tad-pr3-mlops

## Текущее состояние

На первом этапе настроены Git и DVC. Загрузка Fashion-MNIST, обучение моделей, пайплайн и результаты будут добавлены на следующих этапах.

## Управление версиями

Git хранит код, настройки, документацию и метаданные DVC. DVC будет отслеживать наборы данных и обученные модели. Кэш DVC и локальное окружение Python не входят в Git.

Хранилище файлов DVC будет настроено при подготовке данных. Одна копия репозитория GitHub не содержит сами данные и модели.

## Локальное окружение DVC

Команды PowerShell выполняются из корня проекта. При первом получении проекта создайте окружение Python:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dvc.txt
```

На компьютере, где проект уже настроен, повторять установку не требуется. Активация окружения необязательна: команды ниже используют полный относительный путь к DVC.

## Проверка первого этапа

```powershell
git status
git remote -v
.\.venv\Scripts\dvc.exe version
.\.venv\Scripts\dvc.exe status
```

До добавления данных и пайплайна DVC не содержит отслеживаемых наборов данных или этапов обучения.

Для отправки начального коммита в удалённый репозиторий:

```powershell
git push -u origin main
```

Docker-окружение и команды запуска ML-пайплайна будут добавлены на втором этапе.
